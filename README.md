# Trading Backtest Project

This project contains a Python backtesting script and the anonymized trading dataset used for local analysis.
Technical test for Ganymede.
## Structure

- `data/` - trading CSV data files
- `src/` - backtesting and analysis scripts
# Requirmwnts
numpy, pandas,metlolib

## Notes

The dataset file is intentionally ignored by Git so it does not get committed to version control.

## Run

From the project root:

```bash
python src/backtest.py
```
